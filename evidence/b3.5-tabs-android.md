- `android.stage=rpk.verified`
- app/page module load
- `android.stage=initial.command.js`

It then stopped before Mount with:

```text

```

The real `tabs-001.rpk` uses `selected` as a number binding, as required by
the frozen Tabs contract. This is a shared JS Framework initial-binding type
restriction, not an Android Tabs mapping failure. No Android change can
legitimately make this RPK run without modifying the public JS layer or
regenerating the RPK with different semantics.
